# Studio 353 homepage

The portfolio for studio353.com. The owner adds to it by chatting here, in plain language. They are a filmmaker, not a developer: do the work, report in plain words.

- "Add this", "swap that image", "move X up", "remove Y": follow "Adding a project" in README.md from start to finish. A request to add work is the go-ahead to publish it to the preview. Do not ask for a spec or a plan.
- Ask only for what is missing and cannot be looked up, all in one message. Never invent a title, client, year or link.
- Never publish to `live/` without the owner's yes.
- This code may only ever touch the homepage. Nothing may change the Squarespace menu, header or any other page. No site-wide code injection. The guard and the push hook enforce it: never bypass them.
- Work from this folder: `git config core.hooksPath` must print `hooks`.
